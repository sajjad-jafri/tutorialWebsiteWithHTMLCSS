Series

A Series is a one-dimensional labeled array capable of holding any data type (integers, strings, floating-point numbers, Python objects, etc.).

It’s similar to a column in a spreadsheet or a database table.



Creating a Pandas Series

A Pandas Series is like a single column of data in a spreadsheet.

Each value in a Series is associated with an index, which makes data retrieval and manipulation easy.


Example

import pandas as pd

# Creating an empty Series
ser = pd.Series()
print(ser)

# From a list
ser1 = pd.Series([10, 20, 30, 40])
print("Using a List:",ser1)

# Using range()
ser = pd.Series(range(5,10))
print("Using range()",ser)

# With custom index
data = [10, 20, 30, 40]
ser2 = pd.Series(data, index=['a', 'b', 'c', 'd'])
print("With custom index:",ser2)

# From a dictionary
data = {'a' : 'apple', 'b' : 'ball', 'c' : 'cat'}
ser3 = pd.Series(data)
print("Using a dictionary:",ser3)

🔍 Accessing Elements

# Accessing by label
print('Element at index b:',ser3['b'])

# Accessing by loc - location by label
print('Element at index b using loc:',ser3.loc['b'])

# Accessing by iloc/integer-position - location by integer index
print('Element at 2nd integer position:',ser3.iloc[2])

# Accessing keys
print('Keys: ',ser3.keys())

# Update the value
ser3.loc["c"] = "caterpillar"
print(ser3)

Output

Element at index b: ball

Element at index b using loc: ball

Element at 2nd integer position: cat

Keys:  Index(['a', 'b', 'c'], dtype='object')

a          apple
b           ball
c    caterpillar
dtype: str


🧠 Key Features of a Pandas Series

  • Labels (Index): Each element has an associated label (index), which can be customized.

  • If you have specified the label explicitly, still you can access the elements via default index (0,1,2...) using iloc

  • You can create a Series from:

    • Lists or arrays

    • Dictionaries (keys become labels)

    • Scalar values (repeated across index)



Filter by value

import pandas as pd

data = [100, 106, 181, 200, 206]
series = pd.Series(data)

# Filter by any value which are 200 or greater
print(series[series >= 200])

Output

3    200
4    205
dtype: int64


⚙️ Common Operations

Let's take the sales data for 1st and 2nd quarter with an example:

q1 = {'Japan':80, 'China': 450, 'India':200, 'USA': 250}
q2 = {'Brazil':100, 'China': 500, 'India':210, 'USA': 260}

sales_q1 = pd.Series(q1)
sales_q2 = pd.Series(q2)

print(sales_q1 *2) # broadcast the multiplication to each element

print('Mean for q1: ',sales_q1.mean())
print('Mean for q2: ',sales_q2.mean())

# Sum of values of q1
print("Sum of values in quarter1: ',sales_q1.sum())

# Sum of sales of both quarter
sum_q1_q2 = sales_q1 + sales_q2
# Notice in the output:
# We got NaN for Brazil and Japan
# This is one more importance of explicit label indexes.
# It matches same label index and summed up

# In case you want to print Brazil and Japan sale for individual quarter
print(sales_q1.add(sales_q2, fill_value=0)
