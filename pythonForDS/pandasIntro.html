Pandas is a powerhouse Python library for data manipulation and analysis.


🧠 Uses

  • Reading & Writing data in many formats

  • Cleaning and transforming data

  • Filtering and querying

  • Handle missing data

  • Aggregating and visualizing



📦 Pandas provides two core data structures:

  • Series:A one-dimensional labeled array.

  • DataFrame:A two-dimensional table with rows and columns.



Series

A Series is a data structure that holds an 1-D array of information or data along with a named index.

It can hold any data type data. You can store integers, floats, strings, or even Python objects.


Example

import pandas as pd

# From a list
data = [10, 20, 30, 40]
ser = pd.Series(data)
print(ser)

Output

0    10
1    20
2    30
3    40
dtype: int64


Here, 0, 1, 2, 3 are the default index labels. You can also set custom labels: 

import pandas as pd

data = [10, 20, 30, 40]
ser = pd.Series(data, index=['a', 'b', 'c', 'd'])
print(ser)
print('Element at index b:',ser['b']) # Accessing single element

Output

a    10
b    20
c    30
d    40
dtype: int64

Element at index b: 20


🧠 Bonus Tip:

You can create a Series from:

  • Lists or arrays

  • Dictionaries (keys become labels)

  • Scalar values (repeated across index)
