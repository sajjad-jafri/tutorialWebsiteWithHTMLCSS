Pandas is a powerful Python library for data manipulation and analysis.


🧠 Uses

  • Reading & Writing data from many formats like CSV, Excel and SQL databases.

  • Cleaning and transforming data

  • Filtering and querying

  • Handle missing data

  • Aggregating and visualizing



📦 Pandas provides two core data structures:

  • Series: A one-dimensional labeled array.

  • DataFrame: A two-dimensional table with rows and columns.



Series

A Series is a data structure that holds an 1-D array of information or data along with a named index.


It can hold any data type data. You can store integers, floats, strings, or even Python objects.



DataFrame

A DataFrame is a two-dimensional, size-mutable and potentially heterogeneous tabular data structure with labeled axes (rows and columns).
