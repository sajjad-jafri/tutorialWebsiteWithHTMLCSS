What is NumPy?

NumPy stands for Numeric Python is a python library for working with arrays and mathematical operations in Python. It is a fundamental package for scientific computing and data analysis in Python.


🔍 Key Features

Multi-dimensional arrays:

NumPy provides support for single-dimensional (1-D) array and multidimensional (N-D) array elements (matrices) which are essential for numeric computations.


Vectorized operations:

NumPy allows you to perform operations on entire arrays at once, making it much faster than working with Python lists.


Mathematical functions:

NumPy provided a wide range of mathematical functions, including basic arithmetic, linear algebra, trigonometric, exponential, fourier transform, and statistical functions.



🧠 Advantages:

Speed:

While NumPy structures look similar to standard Python lists, NumPy is much faster and efficient than working with Python lists, making it ideal for large-scale numeric computations.


Effiecient memory usage:

NumPy arrays use less memory than Python lists, which is important when working with large datasets.


Convinient

NumPy is very convenient and efficient with Matrix multiplication and data reshaping.


Different flavours:

Numpy arrays essentially come in two flavors: Vectors and Matrices. Vectors are strictly 1-d arrays and matrices are 2-d (but you should note a matrix can still have only one row or one column).



You can install NumPy simply using pip command in your command prompt window using 'pip install numpy'

One Dimensional Array:

A one-dimensional array is a type of linear array.

One Dimensional Array
1 2 3 4

Python Code


  # importing numpy module
  import numpy as np

  # creating list
  l = [1, 2, 3, 4]

  # Creating numpy array
  arr = np.array(l)

  print("List in Python: ", l)
  print("Numpy Array in Python: ", arr)

Output:

        
  List in Python:  [1, 2, 3, 4]
  Numpy Array in Python:  [1 2 3 4]



Multi-Dimensional Array:

Data in multidimensional arrays are stored in tabular form.

Two Dimensional Array
1 2 3 4
5 6 7 8

Python Code

	
  # importing numpy module
  import numpy as np

  # creating list
  list_1 = [1, 2, 3, 4]
  list_2 = [5, 6, 7, 8]

  # Creating numpy array
  arr = np.array([list_1, list_2])


  print("Numpy multi dimensional array in Python:\n ", arr)

Output

	
  Numpy multi dimensional array in Python:
    [[1 2 3 4]
   [5 6 7 8]]

Note: use [ ] operators inside numpy.array() for multi-dimensional
