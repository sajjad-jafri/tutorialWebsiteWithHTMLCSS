🔍 SELECTION

We can Access the DataFrame using selection the portion of a DF.

Selecting data helps efficiently retrieve specific rows, columns or subsets from a DataFrame.


We already have one df:

	Name    Age    City
Emp 1   Alice   25     New York
Emp 2   Bob     30     Paris
Emp 3   Charlie 35     London
Emp 4   Greg    42     Washigton
Emp 5   Harry   22     London


1. Selection by Columns

# Selecting the 'Age' column
age_column = df['Age']
print(age_column)

# Selecting multiple columns
cols = df[['Name','Age']]
print(cols)

2. Selection by Row/s

To access specific rows in a DataFrame, you can use:

  • loc (for label-based indexing) or

  • iloc (for positional indexing).

# Selecting by label
print('Employee 2:\n',df.loc['Emp 2'])

# Selecting by integer-position
print('Employee 3:\n',df.iloc[2])

Output

Employee 2:
Name      Bob
Age        30
City    Paris
Name: Emp 2, dtype: object

Employee 3:
Name    Charlie
Age          35
City     London
Name: Emp 3, dtype: object

Note: One thing to be noted here is when we want one or some specific rows, it will be hard to remember its label.

3. Row & Column together

Before selecting Row & Column together, let's study loc and iloc in more details.


loc and iloc are indexers used to select rows and columns from a DataFrame or Series.

1. loc — Label-based indexing

loc selects data by labels (row labels and column names).

Example

df = pd.DataFrame({
    "name": ["Alice", "Bob", "Charlie"],
    "age": [25, 30, 35],
    "salary": [50000, 60000, 70000]
}, index=["a", "b", "c"])

print(df)

Output

      name  age  salary
a    Alice   25   50000
b      Bob   30   60000
c  Charlie   35   70000
			


# Select a row by label
print(df.loc["a"])

# Select multiple rows
print(df.loc[["a", "c"]]

# Select rows and columns
print(df.loc["a":"c", ["name", "salary"]]

Output

Row by label:
name      Alice
age          25
salary    50000
Name: a, dtype: object

Select multiple rows:
      name  age  salary
a    Alice   25   50000
c  Charlie   35   70000

Select rows and columns
      name  salary
a    Alice   50000
b      Bob   60000
c  Charlie   70000

2. iloc — Integer-position-based indexing

iloc selects data by integer position, similar to Python lists.


Example

# Select first row
print(df.iloc[0])

# Select multiple rows
print(df.iloc[[0, 2]])

# Select rows and columns
print(df.iloc[0:2, 0:2])

Output

Select first row:
name      Alice
age          25
salary    50000
Name: a, dtype: object

Select multiple rows:
      name  age  salary
a    Alice   25   50000
c  Charlie   35   70000

Select rows and columns
    name  age
a  Alice   25
b    Bob   30


Conclusion

loc or iloc takes two selectors:

df.loc[rows, columns]


When you see:

df.loc['A']

It is just shorthand for:

df.loc[['A'], :]

Pandas treats it as:

  • row label = 'A'

  • all columns



Common valid row selectors for .loc

df.loc['row_label'] 	# for 1 row
df.loc[['row1', 'row2']]	# for multiple rows
df.loc['row1':'row5'] 	# from row 1 to row 5
df.loc["row1":"row4", ["col1","col3"]] 	# multiple rows and columns togeather
df.loc[boolean_series]

same will be for .iloc but with integer position



Let's understand df.loc[boolean_series] with one example


Example:

let's take one df, in which we have 2 column - record and description.

We want to print record number for description value in None or empty string.


Step 1: Create a sample DataFrame

df = pd.DataFrame({
    "record": ["R001", "R002", "R003", "R004"],
    "description": ["Valid entry", "", None, "Another valid entry"]
})
print(df)
			

   record         description
0   R001          Valid entry
1   R002
2   R003                  NaN
3   R004  Another valid entry


Step 2: Create the boolean mask/series (empty_desc_series)

We want rows where desc is empty or missing.

empty_desc_series = df["description"].isna() | (df["description"] == "")

This produces a boolean Series:

0    False
1     True
2     True
3    False

Step 3: Use loc and convert to list

records = df.loc[empty_desc_series, "record"].tolist()

# Final Output
print(records)
			
['R002', 'R003']
