A Pandas DataFrame is one of the most powerful and widely used data structures in Python for data analysis and manipulation.


A DataFrame is essentially a 2-dimensional labeled data structure — think of it like a spreadsheet or SQL table, with rows and columns.


📦 Key Features

  • Labeled axes: Rows and columns have labels (index and column names).

  • Heterogeneous data: Each column can hold different data types (e.g., integers, strings, floats).

  • Missing data handling: Built-in support for NaNs and flexible fill/drop options.

  • Powerful operations: Filtering, grouping, merging, reshaping, and more.

🛠️ Creating a DataFrame

import pandas as pd

data = {
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Paris', 'London']
}

df = pd.DataFrame(data)
print(df)

Output

     Name    Age    City
0    Alice   25     New York
1    Bob     30     Paris
2    Charlie 35     London

🧠 Key Features of a Pandas Series

  • Labels (Index): Each element has an associated label (index), which can be customized.

  • If you have specified the label explicitely, still you can access the elements via default index (0,1,2...) using iloc

  • You can create a Series from:

    • Lists or arrays

    • Dictionaries (keys become labels)

    • Scalar values (repeated across index)



⚙️ Common Operations

Lets take the sales data for 1st and 2nd quarter with an example:

q1 = {'Japan':80, 'China': 450, 'India':200, 'USA': 250}
q2 = {'Brazil':100, 'China': 500, 'India':210, 'USA': 260}

sales_q1 = pd.Series(q1)
sales_q2 = pd.Series(q2)

print(sales_q1 *2) # broadcast the multiplication to each element

print('Mean for q1: ',sales_q1.mean())
print('Mean for q2: ',sales_q2.mean())

# Sum of values of q1
print("Sum of values in quarter1: ',sales_q1.sum()) 

# Sum of sales of both quarter
sum_q1_q2 = sales_q1 + sales_q2
# Notice in the output:
# We got NaN for Brazil and Japan
# This is one more importance of explicit label indexes.
# It matches same label index and summed up

# In case you want to print Brazil and Japan sale for individual quarter
print(sales_q1.add(sales_q2, fill_value=0)
