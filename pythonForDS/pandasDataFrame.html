A Pandas DataFrame is one of the most powerful and widely used data structures in Python for data analysis and manipulation.


A DataFrame is a two‑dimensional, labeled, tabular data structure with rows and columns—very similar to a table in a database or an Excel spreadsheet.



📦 Key Features

  • Contains rows and columns


  • Labeled axes: Rows and columns have labels (index and column names).


  • Heterogeneous data: Each column can hold different data types (e.g., integers, strings, floats).


  • Missing data handling: Built-in support for NaNs and flexible fill/drop options.


  • Powerful operations: Filtering, grouping, merging, reshaping, and more.



Conceptually:

Name Age City
0 Alice 25 Delhi
1 Bob 30 Mumbai
2 Charlie 28 Chennai

🛠️ Creating a DataFrame


1. From a dictionary

import pandas as pd

data = {
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Paris', 'London']
}

df = pd.DataFrame(data)
print(df)

Output

     Name    Age    City
0    Alice   25     New York
1    Bob     30     Paris
2    Charlie 35     London


We can pass the custom index using:

df = pd.DataFrame(data, index = ['Emp 1', 'Emp 2', 'Emp 3'])

Output

	Name    Age    City
Emp 1   Alice   25     New York
Emp 2   Bob     30     Paris
Emp 3   Charlie 35     London


2. From a list of lists


data = [
    ["Alice", 25, "Delhi"],
    ["Bob", 30, "Mumbai"],
    ["Carol", 28, "Chennai"]
]

df = pd.DataFrame(data, columns=["Name", "Age", "City"])


Reading CSV/JSON Files with Pandas

CSV files are Comma-Separated values files that allow storage of tabular data.


To access data from the CSV file, we require a function read_csv() from Pandas that retrieves data in the form of the data frame.

df = pd.read_csv("pokemon.csv")
print(df)

If you want to print all the data of a df, we can use to_string() function.

print(df.to_string())

Be careful, when working with very large files.




Read specific columns using read_csv

df = pd.read_csv("pokemon.csv", usecols=["Name", "Legendary"])



Using nrows in read_csv()

The nrows parameter limits the number of rows read from a file

df = pd.read_csv("pokemon.csv", nrows=20)



Using skiprows in read_csv()

The skiprows parameter skips unnecessary rows at the start of a file.

df = pd.read_csv("pokemon.csv", skiprows=[4,5,20])



Parsing Dates (parse_dates)

The parse_dates parameter converts date columns into datetime objects, simplifying operations like filtering, sorting or time-based analysis.

df = pd.read_csv("data.csv", parse_dates=["Date of birth"])


Same way, we can use json data.

df = pd.read_json("pokemon.json")
