🧠 Manipulating Data

In pandas, data manipulation refers to the process of programmatically transforming, cleaning, and organizing raw data into a structured and meaningful format suitable for analysis, visualization, and machine learning models.



Adding New Column

import pandas as pd

data = {
    'Name': ['Alice', 'Bob', 'Charlie'],
    'Age': [25, 30, 35],
    'City': ['New York', 'Paris', 'London']
}

df = pd.DataFrame(data)

# Adding a new column
# Using 'Job' as the column name and equating it to the list
df['Job'] = ["Cook", "N/A", "Cashier"]

print(df)

Output

          Name  Age      City      Job
Emp 1    Alice   25  New York     Cook
Emp 2      Bob   30     Paris      N/A
Emp 3  Charlie   35    London  Cashier



Adding New Rows

The easiest way to add new row is to create a dataframe and then concatenate with previous df.

We can add a dictionary for each row in a list. Let's say, we want to add 2 rows then it can be added up like:

new_rows = pd.DataFrame([{},{}])

Example

import pandas as pd

# Already having a DataFrame
print(df)

# Adding 2 new rows
# new_rows will be a new separate DataFrame
new_rows = pd.DataFrame([
	{'Name':'Sandy', 'Age':60, 'City':'Washington', 'Job': 'Engineer'},
	{'Name':'Eve', 'Age':55, 'City':'New York', 'Job': 'Scientist'}
		])

# Concatenating df and new_rows DataFrame
df = pd.concant([df, new_rows])

print(df)

Output

          Name  Age      City      Job
Emp 1    Alice   25  New York     Cook
Emp 2      Bob   30     Paris      N/A
Emp 3  Charlie   35    London  Cashier

After adding new rows:
          Name  Age       City        Job
Emp 1    Alice   25   New York       Cook
Emp 2      Bob   30      Paris        N/A
Emp 3  Charlie   35     London    Cashier
0        Sandy   60  Washigton   Engineer
1          Eve   55   New York  Scientist

However, we didn't set the index, so index is set to 0 and 1. We could pass the index:

new_rows = pd.DataFrame([{row1 data}, {row2 data}], index = ['Emp 4', 'Emp 5'])




Delete rows/columns from DataFrame

Drop() is used to remove rows or columns by specifying label names and corresponding axis, or by directly specifying index or column names.


Syntax: DataFrame.drop(labels=None, axis=0, index=None, columns=None, level=None, inplace=False, errors='raise')


Parameters:

  • labels: String or list of strings referring row or column name.


  • axis: int or string value, 0 'index' for Rows and 1 'columns' for Columns.


  • index or columns: Single label or list. index or columns are an alternative to axis and cannot be used together.


  • level: Used to specify level in case data frame is having multiple level index.


  • inplace: Makes changes in original Data Frame if True.


  • errors: Ignores error if any value from the list doesn't exist and drops rest of the values when errors = 'ignore'


Return type: the remaining DataFrame after the specified rows/columns are removed



Drop the row using the index

import pandas as pd

# Already having a DataFrame
print(df)

df.drop(index='Emp 2', inplace=True)
print(df)

✅ Best when working with labeled indices.

Dropping Columns with Column Name

Let's understand the concept od axis first. If I try to delete the column Age by just passing:

df = df.drop(['Age'])


It will through an error:

KeyError: "['Age'] not found in axis"


Meaning of axis

axis value What it refers to
axis=0 Rows (index)
axis=1 Columns


Visual example

          Name  Age       City        Job
Emp 1    Alice   25   New York       Cook
Emp 2      Bob   30      Paris        N/A
Emp 3  Charlie   35     London    Cashier
Emp 4    Sandy   60  Washigton   Engineer
Emp 5      Eve   55   New York  Scientist

🔹 Rows (axis=0) → Emp 1, Emp 2, Emp 3, Emp 4, Emp 5
🔹 Columns (axis=1) → Name, Age, City


Dropping a column with column name

df.drop('Age', axis=1, inplace=True)
# OR
df.drop(columns='Age', inplace=True)

# Drop a row
df.drop('Emp 1', axis=0)
# or
df.drop(index='Emp 1')

# Drop multiple columns at once
df.drop(columns=['Age', 'City'], inplace=True)


Delete a column using del

del df['Age']

🔹 Permanent deletion

🔹 Cannot drop multiple columns at once



Using pop() (also returns the column)

age_column = df.pop('Age')

🔹 Removes the column

🔹 Stores the removed column in age_column
