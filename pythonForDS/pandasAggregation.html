Aggregation

Aggregate functions are used to reduces a set of values into a single summary value, such as a sum, mean, min/max, or count.

It is often used with the groupby() function.


Let's take a sample dataframe to proceed further

      Name  Age Team  Score
0    Alice   25    A     10
1      Bob   30    B     30
2  Charlie  Nan    A     20
3     Greg   42    A     10
4    Harry   22    B     40


Aggregation on entire dataframe

print(df.sum())

# numeric_only to consider numeric column only
print(df.sum(numeric_only=True))

# count doesn't include null values
print(df.count())

Output

Name     AliceBobCharlieGregHarry
Age                         119.0
Team                        ABAAB
Score                         110
dtype: object

# numeric_only
Age      119.0
Score    110.0
dtype: float64

# count
Name     5
Age      4
Team     5
Score    5
dtype: int64


Aggregation on single column

print(df["Score"].sum())
print(df["Score"].mean())
print(df["Age"].min())
print(df["Name"].count())

Output

110
22.0
22.0
5


Aggregation with groupby

groupby is used to split data into groups.We can group together rows by something they have in common, perform operations on each group, and then combine the results.


Simply, groupby divides data into groups and lets you analyze each group separately.

group = df.groupby("Team")
print(group)

Output

pandas.api.typing.DataFrameGroupBy object at 0x000001CEA9771430

Note: group is an object, when you apply an aggregate function, the group object will return a series for you to display.


group = df.groupby("Team")
print(group["Score"].sum())

# or simply code
print(print(df.groupby("Team")["Score"].sum())

Output

Team
A    40
B    70
Name: Score, dtype: int64
