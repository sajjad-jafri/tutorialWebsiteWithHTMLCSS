In Generative AI, tokens and tokenization are fundamental concepts because Large Language Models (LLMs) do not process text directly. Instead, they process tokens.


What is a Token?

A token is a small unit of text that an AI model understands and processes.

A token may be:

  • A full word

  • A part of a word (subword)

  • A punctuation mark

  • A number

  • A special symbol


Examples

Text:

I love Generative AI.

Possible tokens:

["I", " love", " Generative", " AI", "."]

Another example:

unbelievable

May be split into:

["un", "believ", "able"]

Note: The exact split depends on the tokenizer used by the model.


What is Tokenization?

Tokenization is the process of breaking text into smaller pieces called tokens so that an LLM can understand and process the input.


Flow

Input Text
     ↓
Tokenizer
     ↓
Tokens
     ↓
Token IDs
     ↓
LLM Processing

Example:

"Hello world"

Tokenized into:

["Hello", " world"]

Then mapped to token IDs:

[15496, 995]

The model works with these numerical IDs, not the original text.


Why Do LLMs Need Tokenization?

Computers do not understand raw text the way humans do. An LLM cannot directly read a sentence like:

"I am learning Generative AI."


First, the text must be split into tokens. Then those tokens are converted into numbers so the neural network can process them.


Without tokenization, the model would not know how to break language into manageable pieces.


Word, Character, and Subword Tokenization

There are different ways to break text into tokens:


  • 1. Word Tokenization:

    Splits a sentence word by word.

    • "I love AI" → ["I", "love", "AI"]


  • 2. Character Tokenization:

    Splits text character by character.

    • "AI" → ["A", "I"]


  • 3. Subword Tokenization:

    Splits text into meaningful parts of words.

    • "playing" → ["play", "ing"]


Most modern LLMs use subword tokenization because it handles unknown words, spelling variations, and rare words more efficiently.


Context Window

Every model has a maximum number of tokens it can handle at once.

In LLMs, input size is usually measured in tokens, not words.


This is important because every model has a context window, which means it can only read a limited number of tokens at one time.


Example:

  • A short sentence may take only a few tokens.

  • A long article may contain thousands of tokens.


When you send a prompt to ChatGPT or Copilot: 

Total Tokens = Input Tokens + Output Tokens

This is important because LLM pricing and context limits are usually based on token count.

Example:

Model Context Window = 128K tokens

This includes:

User Prompt
+ System Instructions
+ Conversation History
+ Generated Response

Why Tokens Matter for GenAI Developers

As a GenAI developer, understanding tokens helps with:

Cost Optimization

  • Fewer tokens = lower API cost.


Performance

  • Shorter prompts lead to faster responses.


Context Management

  • Stay within model token limits.


Prompt Engineering

  • Efficient prompts improve quality and reduce costs.


Tokenization Using Python


1. Basic Tokenization Using Python

text = "I love Generative AI."

# Split by spaces
tokens = text.split()

print("Tokens:", tokens)
print("Number of tokens:", len(tokens))

Output

Tokens: ['I', 'love', 'Generative', 'AI.']
Number of tokens: 4

This is simple but not how modern LLMs tokenize text.



2. Tokenization Using NLTK

import nltk
from nltk.tokenize import word_tokenize

nltk.download('punkt')

text = "I love Generative AI."

tokens = word_tokenize(text)

print(tokens)
print("Token Count:", len(tokens))

Output

['I', 'love', 'Generative', 'AI', '.']
Token Count: 5

Notice that the period (.) becomes a separate token.



3. GPT/OpenAI Style Tokenization (tiktoken)

import tiktoken

# GPT tokenizer
encoder = tiktoken.get_encoding("gpt2") # gpt2 is the model

text = "I love Generative AI."

tokens = encoder.encode(text)

print("Token IDs:", tokens)
print("Token Count:", len(tokens))

Output: 

Token IDs: [40, 1842, 2980, 876, 9552, 13]
Token Count: 6


4. Convert Tokens Back to Text

import tiktoken

encoder = tiktoken.get_encoding("gpt2")

token_ids = [13681, 0, 4673, 5215, 20185, 318, 922, 2126]

decoded_text = encoder.decode(token_ids)

print("Decoded text:", decoded_text)

Output:

Decoded text: Great! learning GenAI is good idea

We can use encode function to encode text into numeric and decode function for vice versa.



5. Show Individual Tokens

import tiktoken

encoding = tiktoken.get_encoding("gpt2")

text = "I love machine learning"

token_ids = encoding.encode(text)

print("Token IDs:", token_ids)

for token_id in token_ids:
    print(token_id, "->", encoding.decode([token_id]))

Output:

Token IDs: [40, 1842, 4572, 4673]
40 -> I
1842 ->  love
4572 ->  machine
4673 ->  learning


Summary

  • Tokenization is the process of splitting text into tokens.

  • Tokens can be words, subwords, characters, punctuation, or symbols.

  • LLMs use tokens, not raw text, for processing.

  • Modern LLMs usually use subword tokenization.

  • Token count matters because of the model's context window.

  • To play around with tokenization, visit tiktokenizer
